AI readiness of the federal statistical system: host-level findings

Snapshot cycle scan_2026-09-10_rj4 · version 2026-09-10_rj4 · built from commit 354108ace416 on 2026-09-19 (UTC).

Host-level AI-readiness findings for the sixteen recognized agencies and units of the US federal statistical system, plus three federal reference hosts shown separately. Five host-level checks over one measurement cycle with one declared client identity, every verdict traceable to the Finding, the rule version and the retained response body that produced it. The matrices, the per-check source appendix and every registered Result the report quotes are published as data beside it; the PDF is a view of them.

Read the third column before the second. RFC 9309 §2.3 binds robots.txt to an AUTHORITY — scheme, host and port — not to a path prefix. This is a project site, so the authority is the whole of brockwebb.github.io, whose root belongs to a user-site repository this publication does not own. A4, A5, A11-declared, A12 therefore measured that authority and not this publication; only A10, G1-D read https://brockwebb.github.io/ai-readiness-kg/. The fix is a host, not a file — and this row is the instrument reproducing, on itself, the failure mode it exists to detect: declarations sitting somewhere a machine will not read them.

A fail here is reported and left standing, and nothing in this tree was changed to improve one after it was measured. Repairing a site after scanning it is the thing this instrument measures publishers for. Every verdict is a registered Result (self_l0_<leg>_self_2026-09-13) over a Finding naming the rule, its version and the URL above.
