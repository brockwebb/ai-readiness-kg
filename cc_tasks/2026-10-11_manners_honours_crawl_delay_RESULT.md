## 1. Premises
1. *47 requests at 1 req/s to catalog.data.gov, which asks `Crawl-Delay: 10`*: taken from part 2's RESULT (line 3, §5 item 12), not re-fetched (Network: none). *The Fetcher does not read the field*: **true**. The new tests went red on the unchanged Fetcher (§3).

## 2. What changed (decisions 1-4)
- **d1.** Interval to a netloc = `max(1/requests_per_second_per_host, Crawl-delay)`. The delay comes from the group Protego matches for our UA, the same matcher `allowed()` uses (`manners.crawl_delay_of`). A value that is not a finite non-negative number (`soon`, `-5`, `nan`, `inf`, `10s`) is ignored, logged as a WARNING on `scan.manners` and recorded with its line number.
- **d2.** `manners.crawl_delay_max_s: 60`. The rationale is in `params.yaml`: tens of requests per host per cycle, so 60 s already holds a host for most of an hour, and 60 is 6x the largest delay seen applying to this client (catalog.data.gov's 10). Above the ceiling `_gate` refuses every fetch to the netloc except `/robots.txt`, the carve-out paths included. It raises `RobotsDisallowed("<url> (Crawl-delay: 120 s for this client exceeds manners.crawl_delay_max_s 60 s; host not fetched this cycle)")`, so the leg's Observation is `robots_disallowed`, which is BLIND and not requested, and every rule over it returns `error` with the reason on the record. This reuses the class the unreachable-robots refusal already raises; a new error class would have moved `errors.py`, `ERROR_CLASSES`, every payload's `error_class_counts` key set and `tag_requirements.UNMAPPED_ERROR_CLASSES`. `allowed()` is unchanged, because the host permitted the path and only the pace is refused.
- **d3.** Each `robots_log` line, which already goes into the payload via `run.py:810` (unchanged), gains `crawl_delay_s`, `crawl_delay_ignored`, `crawl_delay_max_s`, `interval_s` and `interval_source` (`standing` | `crawl_delay` | `crawl_delay_over_ceiling`). No stored payload moved (`state/` is byte-identical).
- **d4.** The whole `manners.py` diff is in the appendix. `params.yaml` gains only `manners.crawl_delay_max_s`, which the protected-paths script asserts.
