# Readiness diagnostic: what it measures, placed on the USAFacts ladder

Generated by `scripts/readiness_rollup_build.py` from the framework record and the cycle of record.

The readiness diagnostic places its checks on USAFacts' August 2026 framework for AI-ready government data: three tracks, Agentic Access, Agentic Context and Agentic Evaluation, three levels in each, with three prerequisites that hold before any level applies.

That framework grew from USAFacts' earlier guide to *AI-ready data*, whose four criteria the diagnostic first used; the checks are the same readings, re-parented onto the ladder an agency climbs at its own pace.

| USAFacts rung | What the framework asks for | Checks | Quality concern | Agencies passing every check in this rung^a |
|--------------|--------------------------|--------------------------------|----------------|--------------------|
| Prerequisite, discoverable | Data should be registered on Data.gov or otherwise accessible through the open web. | Three checks: The data page is in the site's list of pages (Scored); The page labels itself as a dataset; The product is listed in the agency's data inventory (Scored) | Find and obtain; metadata | zero of sixteen |
| Prerequisite, clearly licensed | The data's usage license stated in plain language on the data product's landing page, not just buried in metadata. | One check: The terms of reuse, under a recognised name | Metadata | zero of sixteen |
| Access I | Data is published in machine-readable files | Six checks: Data offered as a file a program can read (Scored); The whole dataset in one download (Scored); Whether the site's visitor rules let AI tools in; The interactive data tool answers honestly; What the site states about automated access; The site serves what its own rules permit | Find and obtain; usable format | eleven of sixteen |
| Access II | Stable, documented endpoints agents can crawl | Four checks: A published description of the agency's data service; A front door built for programs; From a data page to the data service, terms, change log and inventory; A change history a program can follow | Find and obtain; understand; usable format; metadata | one of sixteen |
| Context I | Definitions and units documented for humans | One check: The methods are readable as plain text | Understand | two of sixteen |
| Context II | Methodology and caveats travel with each dataset | One check: The release date, and a link to the latest release | Metadata | one of sixteen |
| Access III | Agent-native interface for live, structured queries | None |  | none measured |
| Context III | Context is machine-readable and citable in an answer | None |  | none measured |
| Evaluation I | A published evaluation set with reported pass rates | None |  | none measured |
| Evaluation II | Continuous automated evaluation at scale | None |  | none measured |
| Evaluation III | Integrated quality assurance programs across agencies and industry | None |  | none measured |

^a An agency passes a rung when none of the rung's checks that could be measured for it comes back fail; a check not measured for an agency, or not measured on the cycle of record at all, is left out of that agency's count and is never read as a fail.

Checks are placed on USAFacts (2026), *AI-ready data*, August 2026 framework; concerns from FCSM 20-04, Accessibility dimension, after Webb 2026.

Standard user: no key. API user: a free key by open registration, a person completes an email step.
